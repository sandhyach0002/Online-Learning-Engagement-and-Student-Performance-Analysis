# Online Learning Engagement and Student Performance Analysis

#  About the Project

**Online Learning Engagement and Student Performance Analysis** is a Power BI project developed to analyze student learning behavior, engagement, and academic performance in an online education environment.

The project transforms raw student data into an interactive dashboard that makes it easier to understand learning patterns, performance levels, student activity, and retention-related information.

The data was cleaned and prepared using Power Query, and Power BI visualizations and DAX measures were used to create an interactive and informative dashboard.

---

##  Project Objectives

The main objectives of this project are to:

- Analyze student learning and activity data.
- Measure student engagement in online learning.
- Analyze academic performance and final results.
- Identify patterns in student learning behavior.
- Understand student performance and risk levels.
- Monitor factors related to student retention.
- Present the analysis through an interactive Power BI dashboard.

---

##  Dataset

The project uses an **Online Education Dataset** containing information about students, their learning activities, engagement, and academic performance.

### Dataset Features

| Feature | Description |
|---|---|
| Student ID | Unique identification number of the student |
| Gender | Gender of the student |
| Education | Educational background |
| Region | Student's region |
| Student Activity | Student participation and learning activity |
| Engagement | Level of student engagement |
| Clicks | Number of interactions or clicks |
| Score | Student performance score |
| Final Result | Final academic result |
| Performance Level | Categorized performance level |
| Risk Level | Student risk or retention category |

---

##  Data Cleaning & Preparation

The dataset was cleaned and prepared using **Power Query in Power BI** before creating the dashboard.

The major steps included:

- Removing duplicate records.
- Checking and handling missing values.
- Correcting data types.
- Standardizing values and categories.
- Cleaning student activity and performance fields.
- Preparing the data for analysis.
- Creating calculated fields and measures where required.

##  Dashboard

The Power BI dashboard provides an interactive view of student learning and performance.

### Dashboard Analysis Includes

-  Student demographics
-  Learning activity
-  Student engagement
-  Academic performance
-  Final results
-  Performance levels
-  Risk levels
-  Student retention

Users can apply filters and interact with the visualizations to explore different student groups and understand the data from different perspectives.

##  Key Insights

The dashboard helps users understand:

- The overall level of student engagement in online learning.
- Patterns in student learning activity.
- Differences in academic performance.
- The relationship between student activity and performance.
